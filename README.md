# Amtel Batch Subscriber Activator (Chrome Extension)

A lightweight, high-performance Manifest V3 Chrome extension designed strictly for bulk searching and activating existing idle subscriber cards in the Amtel CRM portal (`https://www.crmamtel.com/`).

---

## What's New in Version 1.3

- **Excel & CSV Direct File Upload**: Drag-and-drop or upload `.xlsx`, `.csv`, `.tsv`, or `.txt` files directly. The activator automatically extracts identifiers from the first column (e.g. `637900001057585`), removes terminal `.00` artifacts, and detects IMSI mode automatically.
- **CRM Session Expiry Guard**: Detects session timeouts, login redirects, or authorization modals during long batch runs. Automatically pauses the batch, triggers an audio alarm and desktop alert, and allows seamless **Resume (After Login)** without losing queue position.
- **Streamlined ID Types**: Cleaned up the search mode selector to focus exclusively on telecommunications card identifiers:
  - `⚡ Auto-Detect`
  - `📱 MSISDN`
  - `📶 IMSI`
  - `💳 ICCID`
  *(Removed redundant Account ID and Profile ID modes).*
- **Dedicated Tab & Side Panel Modes (`⤢`)**: Run the activator in a dedicated browser tab or Chrome Side Panel so clicking away never halts your batch.
- **Persistent Background Engine**: The worker runs inside `background.js`, allowing you to close or minimize the extension while cards continue activating on the CRM page.

---

## Core Features

- **Bulk Input Support**: Paste or upload files containing MSISDNs (`71xxxxxxx` or 7-digit suffixes), IMSIs (`6379...`), or ICCIDs (`89252...`).
- **Auto Suffix Cleaning**: Automatically removes `.00` suffixes generated by Excel.
- **Fail-Safe Worker Loop**: Searches each card in sequence. If a card is not found or has an issue, it is logged and skipped automatically so the batch process never crashes.
- **Smart Activation Check**:
  - If a subscriber is **Idle / Unactivated**: clicks the activation control (`check_circle`), confirms any prompt modals, and verifies completion.
  - If a subscriber is **Already Active**: logs as `ALREADY_ACTIVE` and moves to the next card.
  - If a card is **Not Found**: logs as `NOT_FOUND` and skips to the next card.
- **Comprehensive Summary Report**:
  - Summary metrics dashboard (Total, Found, Activated, Already Active, Skipped/Failed).
  - Filterable detailed list of all processed items.
  - **Copy Report** to clipboard, **Download CSV**, or **Download JSON** export.

---

## Installation & Setup

1. Open Chrome and go to `chrome://extensions`.
2. Enable **Developer mode** in the top right.
3. Click **Load unpacked** (or click the **Reload 🔄** icon if already installed).
4. Select this directory: `amtel-batch-activator`.
5. Open your Amtel CRM session (`https://www.crmamtel.com/`).
6. Click the extension icon in your toolbar, or click `⤢` in the header to open it in a dedicated tab.
